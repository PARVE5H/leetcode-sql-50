# LeetCode SQL 50

A complete collection of my solutions to the **LeetCode SQL 50** study plan.

This repository contains SQL solutions for all 50 problems, covering fundamental to intermediate SQL concepts commonly used in **Data Analytics, Business Intelligence, and Data Analyst** roles.

## About

The **SQL 50** study plan by LeetCode is designed to strengthen SQL fundamentals through 50 carefully selected problems.

The problems in this repository cover topics such as:

* SELECT statements
* Filtering and sorting
* String manipulation
* Aggregate functions
* GROUP BY and HAVING
* JOINs
* Subqueries
* CASE statements
* Date and time functions
* Window functions
* Common Table Expressions (CTEs)
* Data transformation and analysis

## Database

The solutions are primarily written using **MySQL-compatible SQL syntax**.

Some SQL functions or syntax may differ between MySQL, PostgreSQL, SQL Server, and other database systems.

## Learning Approach

For each problem, I focus on understanding:

**Problem → Approach → SQL Query → Result**

Rather than simply memorizing queries, the goal is to understand why a particular SQL technique works and when it can be applied to similar problems.
